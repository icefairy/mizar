核心特性

🚀 单个静态二进制

~20-30MB，无运行时依赖，无需 npm / Python / Docker，拷一个文件到目标机器即可运行。

🧩 TS/JS 插件热重载

内嵌 esbuild 编译 TS，JS 免编译直跑 goja，修改即生效，无需重启。

📄 SKILL.md 技能

纯文本技能文件，兼容 Anthropic/Hermes 生态，frontmatter 解析后按需注入上下文。

🔌 MCP 协议

接入任意语言实现的 MCP 服务器，工具生态不再受限。

🖥️ 交互式 TUI

基于 tview，支持鼠标滚动、多行编辑、Tab 补全、流式输出与等待进度指示。

⚡ 本地 bash 直执行

输入 !ls -la 直接在本地跑 shell，命令与输出都纳入对话历史，模型可基于结果继续推理。

🌐 Server 模式

持久运行，提供 OpenAI 兼容 / JSON-RPC 2.0 / WebSocket 三种接入方式。

🧠 结构化长期记忆 /memory

~/.mizar/memory/MEMORY.md 四分类（user/feedback/project/reference）事实清单，每会话自动注入系统提示；memory 工具 / /memory 命令写入当轮即生效，与 HMEM 语义检索插件互补。

🌿 git worktree 隔离

worktree_create/leave/list 全走 git 官方命令，实验性改动失败可整体丢弃、不自动 merge；delegate_task.working_dir 真正锚定子代理的 bash/read/write/grep/find/ls。

🪶 延迟工具加载 tool_search

tool_inject_mode=index 时工具 schema 按需加载，长尾工具只列索引不占满上下文；tool_search 按名称/关键词加载，会话内保持可用。

🔐 项目信任 /trust

首次进入含项目级 AGENTS.md / .cursorrules / USER.md / .mizar/prompts 的目录询问一次，未信任跳过注入（防提示注入）；非交互按拒绝不阻塞。

📤 会话导出 HTML -export

单文件自包含 HTML：无 CDN、代码高亮、工具折叠、XSS 转义，内网离线可看；mizar -export -session <id> / -export -c / /export。

🖼️ 图片读取（多模态）

image_read=true 时 read 遇图片文件转视觉附件，LLM 编码为多模态 content 数组（data: URI）；默认关闭，需多模态网关。

🛡️ 权限门禁四模式

auto / default / acceptEdits / plan，bash 命令级危险匹配，主代理与子代理共用同一门禁；/permission 切换并持久化。

🧵 子任务治理

并行委派 + 进度推送（TUI/WebUI）、句柄落盘回放、per-subagent token 计量、只读角色工具层摘写、自定义子代理类型、/fork 分支、用户级 hooks。

🧭 学习闭环 /learn

技能图谱（技能/记忆节点 + related_skills 边 + 词法重叠边）+ 反思（孤岛技能/高频工具/记忆脱节/技能未使用四类可执行洞察）；/learn graph / /learn reflect / /learn json。

🔎 会话全文搜索 session_search

SQLite FTS5 增量索引（trigram，中英文子串可搜），跨全部历史会话检索；搜索/上下文/整段/列表四模式；/search 命令同源。

📌 待办压缩后重注入

压缩成功即把未完成待办重新注入消息流（只注 pending），修「压缩后遗忘待办」缺陷。
