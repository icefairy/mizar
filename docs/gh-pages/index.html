核心特性

🚀 单个静态二进制

~20-30MB，无运行时依赖，无需 npm / Python / Docker，拷一个文件到目标机器即可运行。

🧩 TS/JS 插件热重载

内嵌 esbuild 编译 TS，JS 免编译直跑 goja，修改即生效，无需重启。

📄 SKILL.md 技能

纯文本技能文件，兼容 Anthropic/Hermes 生态，frontmatter 解析后按需注入上下文。

🔌 MCP 协议

接入任意语言实现的 MCP 服务器，工具生态不再受限。

🖥️ 交互式 TUI

基于 tview，支持鼠标滚动、多行编辑、Tab 补全、流式输出与等待进度指示。

🌐 Server 模式

持久运行，提供 OpenAI 兼容 / JSON-RPC 2.0 / WebSocket 三种接入方式。

快速开始

# 下载单个文件（内网/离线首选） curl -O http://192.168.1.10:8080/mizar-linux-amd64 chmod +x mizar ./mizar # 启动后配置（TUI 内执行） /provider <baseURL> <apiKey> /model <name> /think <level>

Server 模式

持久运行，提供 OpenAI 兼容 / JSON-RPC 2.0 / WebSocket 接入。

自举示例

让它写一个插件：./mizar "写一个插件：每天9点检查磁盘占用，超80%告警"
