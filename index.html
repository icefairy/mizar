核心特性

🚀 单个静态二进制

~20-30MB，无运行时依赖，无需 npm / Python / Docker，拷一个文件到目标机器即可运行。

🧩 TS/JS 插件热重载

内嵌 esbuild 编译 TS，JS 免编译直跑 goja，修改即生效，无需重启。

📄 SKILL.md 技能

纯文本技能文件，兼容 Anthropic/Hermes 生态；支持子目录布局 <name>/SKILL.md（可携带 references/ 等附属文件），frontmatter 解析后按需注入上下文。

🔌 MCP 协议

接入任意语言实现的 MCP 服务器，工具生态不再受限。

🖥️ 交互式 TUI

基于 tview，支持鼠标滚动、多行编辑、Tab 补全、流式输出与等待进度指示。

🌐 Server 模式

持久运行，提供 OpenAI 兼容 / JSON-RPC 2.0 / WebSocket 三种接入方式，另含浏览器 Web UI 与管理接口。API 详见 docs/api.md。

🖥️ Web UI

内嵌式浏览器界面：多会话管理、模型/参数设置、流式输出、暗黑主题、完整 Markdown 渲染（表格/代码块/任务列表）；Agent 过程默认折叠分组，回复一目了然。

📦 内置插件与技能

常用插件（数据库增删改查、图片识别）与技能（交接、记忆、数据库）随二进制发布，首次运行自动释放到 ~/.mizar，只补缺不覆盖。

🔍 诊断日志

关键事件落盘 ~/.mizar/logs（TUI/Agent/LLM/panic），三步定位「任务莫名中止/卡死」：看 RUN 边界、ESC 取消、finish_reason。

最新动态

v0.5.0 · 插件启用/禁用/重载 + 记忆自托管

新增 /list_plugins、/enable_plugin、/disable_plugin、/reload_plugins，可切换插件后端（如用 HMEM 版记忆替代内置版，与其它 agent 共用记忆）；记忆插件改为自托管 SQLite，中文二元组分词检索、默认返回 3 条，零外部服务。

v0.4.8 · Agent 过程分组折叠

一轮对话组织为「用户提问 → 工作过程（默认折叠）→ 最终答复」；工具调用/结果压缩为单行、去除空气泡；修复用户多行消息被挤成一行。

v0.4.7 · Web UI 体验增强

侧栏锁定常驻、暗黑/明亮主题、快捷参数行、Markdown 渲染与逐条复制、消息左右对齐；设置新增最大历史条数。

v0.4.6 · Web UI + 溢出兜底

内嵌浏览器 Web UI（多会话 / 模型参数 / 流式输出 / 侧栏收起）；上下文溢出时强制压缩兜底，不再因 400 后无法压缩而失败。

完整变更见 docs/changelog.md。

快速开始

# 下载单个文件（内网/离线首选） curl -O http://192.168.1.10:8080/mizar-linux-amd64 chmod +x mizar ./mizar # 启动后配置（TUI 内执行） /provider <baseURL> <apiKey> /model <name> /think <level> # 或持久化运行：Server + 浏览器 Web UI ./mizar --serve --addr :3003 # 浏览器打开 http://127.0.0.1:3003/web/（首次启动生成登录密码）

Server 模式

持久运行，提供 OpenAI 兼容 / JSON-RPC 2.0 / WebSocket / 浏览器 Web UI，详见 docs/api.md。

内置插件与技能

首次运行自动释放到 ~/.mizar/extensions 与 ~/.mizar/skills（只补缺不覆盖，--no-assets 可关闭）。开箱即用数据库操作、图片识别、交接与记忆能力。

自举示例

让它写一个插件：./mizar "写一个插件：每天9点检查磁盘占用，超80%告警"
